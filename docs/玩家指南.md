# 玩家指南

> 面向第一次玩的玩家。想看完整规则与数值，去游戏内的「规则」页，或读 [规则设定.md](规则设定.md)。

## 一、这是什么游戏

两名玩家各自拿到 **6 名星灵**，从中选出 **3 名**排好出击顺序、分配 **4 次增益**、定下攻击策略，
然后交给系统自动演算整场战斗。**三局两胜**。

一句话：你不是在操作战斗，而是在**猜对手会怎么布阵**，然后把自己的部署塞进对手的软肋里。

## 二、30 秒上手

1. 首页填昵称 → 点「创建房间」，拿到 4 位房间号；
   - 先在**游戏模式**里选一个：标准（角色自带标签）/ 混沌（标签随机分配）/ 大战场（9 选 5）；
2. 点「**复制邀请链接**」发给对手（对方打开链接会自动填好房间号），或直接告诉他房间号；
   - 不想等？点「**随机匹配**」：系统会把两个点了匹配的人直接配到一起，排队时随时可以取消；
3. 两人到齐后自动进入第一局：
   - **把手牌拖到出击位**选出 3 名（也可以直接点卡牌，会自动落到最前面的空位）；
     拖动已上阵的卡可以调整顺序，把卡拖回手牌区就是下阵；
   - 不想拖就点右上角「**切到按钮视图**」：点角色依次落位，再点两个出击位交换；
     两种视图共用同一份方案，随时切换都不会丢；
   - 用 `+ 攻击` / `+ 生命` 给位置分配 4 次增益，同一个位置最多 2 次；
     （先点筹码，再点位置；手里握着筹码时可以连续点多个位置；再点一次同一筹码就取消）
   - 选一个攻击策略；
   - 点「提交方案」（方案不合法时按钮旁边会告诉你还差什么）；
4. 双方都提交后自动开战：两军左右对峙，冲刺、弹道、伤害飘字、阵亡碎裂会一条条演出来，
   血条实时变化。看的时候可以：
   - **暂停 / 继续**（空格键也行）、**1× → 2× → 4×** 加速；
   - **跳到关键节点**（下一个阵亡 / 复活 / 回合开始，→ 键也行）；
   - **跳到结果**（不想看直接进结算）、**展开战报**（逐行文字记录，L 键）；
   - **重播**：回看这一局任意一局是怎么打的；
5. 先赢 2 局的一方获胜。结束后两边都点「再来一局」，就可以直接开新对局。

> 音效默认开启，左上角「🔊 音效」可以随时静音，选择会记住。
> 拖牌时鼠标按住移动即可；手机上按住卡牌约 0.15 秒再拖，避免和页面滚动打架。
> 键盘也能操作：`1`~`9` 把对应手牌上阵/收回，`Backspace` 撤销，`Enter` 提交。

> 准备阶段限时 **60 秒**，最后 10 秒倒计时会变红；超时会由系统随机提交一份方案。
>
> 网络抖动、或者不小心刷新了页面也不用慌：房间会保留 **90 秒**等你回来，
> 重新打开页面会自动回到原来的座位，已经提交的方案也还在；
> 对手掉线时你会看到提示，对局进度不会丢。

## 三、界面速查

| 界面 | 你在做什么 |
| --- | --- |
| 大厅 | 填昵称、创建或加入房间；下方会显示你最近 5 场的战绩 |
| 等待页 | 等对手进来；可复制房间号或邀请链接 |
| 备战页 | 拖牌（或切按钮视图）选人、排顺序、分配增益、选策略；右上角有倒计时，顶部横幅显示上一局结果 |
| 战斗页 | 看两军对峙的战斗演出；可暂停、加速、跳关键节点、跳到结果、展开战报、重播 |
| 结算 | 看本局比分与原因；整场结束时显示每局胜负，可点「再来一局」 |

### 3.1 备战页怎么用（按钮模式）

| 操作 | 怎么做 |
| --- | --- |
| 上阵 | 点角色卡；或直接按数字键 `1`~`9` 选对应位置的卡 |
| 调顺序 | 点「交换位次」→ 再点另一个出击位，一步换好（「只能放在首位」的角色不参与交换） |
| 加增益 | 先点上方筹码「攻击 +2 / 生命 +4」，再点出击位；拿起筹码时所有出击位会高亮 |
| 减增益 | 点出击位上的增益标记（`攻击 +2 ×`）即可取消 |
| 撤销 | 点「撤销」或按 `Backspace`；「清空」会重置整套方案 |
| 提交 | 点「提交方案」或按 `Enter`（方案不合法时按钮是灰的） |

页面右下角还有两个辅助面板：

- **阵容指标**：当前出战阵容的**先手值总和**（并给出「本池最低可能」作为参考）、总攻击、总生命、标签构成。
  先手值越低越容易抢到先手，这是这套游戏里最容易被忽略的取舍；
- **提交检查清单**：选人 / 增益 / 策略三项逐条打勾，全部打勾才能提交。

## 四、进阶技巧

### 4.0 三种模式怎么选

| 模式 | 什么时候玩 |
| --- | --- |
| 标准模式 | 想熟悉角色与标签的固定搭配，也适合认真博弈 |
| 混沌模式 | 想每局都有新花样：角色还是那些角色，但标签每局重抽，可能出现"会吸血的盾卫"这类组合 |
| 大战场模式 | 想打 5v5：人多了以后群伤、护盾、复活这类团队标签明显更强 |

> 不同模式的玩家不会被匹配到一起，房间也是互相隔离的。

### 4.1 先手值：一种会被忽略的货币

每名角色都有一个**先手值**。双方出战角色的先手值**总和较低的一方先出手**（相同时随机）。

设计上，越强的角色先手值越高——也就是说，"用强力角色"和"抢到先手"通常只能二选一。
如果你的阵容是脆皮爆发，抢先手往往比多 1 点攻击更值。

### 4.2 攻击策略怎么选

| 策略 | 什么时候用 |
| --- | --- |
| 优先攻击当前血量最低 | 默认选择，配合群伤/穿透能快速滚雪球，稳定收割 |
| 优先攻击攻击力最高 | 对方有明显核心（狂战士、处决者、重炮统领）时，优先斩首 |
| 优先攻击指定标签 | 想点掉对方的**复活/护盾/重装**这类关键支援时，用它集火 |

### 4.3 增益怎么分

- 一共 4 次，单个角色最多 2 次；
- 常见分法：给主力 2 次（攻 + 血），给第二个输出或前排各 1 次；
- 脆皮角色补 1 次生命，往往比补攻击更能活到出手；
- 别忘记：增益也可以全给同一个人 2 次——前提是你敢赌他活到出手。

### 4.4 标签之间的克制关系（记这几条就够）

| 你的角色 | 怕什么 / 克什么 |
| --- | --- |
| 自爆步兵 | 一定放首位，优先炸"能一次带走"的脆皮；遇到重装/护盾会被浪费 |
| 诅咒巫师 | 开战就剥夺对方一个标签，专治依赖标签的核心（复活、护盾、狂暴） |
| 死灵法师 | 能把队友拉回来一次；自己死了能力就失效，注意保护 |
| 铁甲卫士 / 晶壁守卫 | 减免大伤害；被大量小伤害（群伤、中毒）磨着更难受 |
| 护盾部署者 | 为队友挡一半伤害；遇到自爆时形同虚设 |
| 风行射手 / 暗影猎手 | 专打脆皮，命中脆皮后还会追击另一个目标 |
| 狂战士 / 血怒斗士 | 血量掉到 14 以下时伤害暴涨，尽量在爆发前解决或提前集火 |
| 毒药投手 | 持续掉血、可叠加，越拖越难受；速攻压制他 |
| 重炮统领 | 打全场，但先手值最高、很难抢到先手，也很脆 |
| 噬魂者 | 打多少回多少，但单次回复有上限，被高爆发压着打很难受 |
| 荆棘守卫 | 反弹 40% 伤害，别用小伤害去磨他；自爆伤害不吃反弹 |
| 处决者 | 对方残血时伤害 ×1.5，是收尾的人，别让他活到最后 |

### 4.5 常见误区

- ❌ 想把 4 次增益全给一个人 → 规则不允许，单个位置最多 2 次；
- ❌ 把自爆步兵放在第 2、3 位 → 会被规则拦住，它只能站首位；
- ❌ 只看面板不看先手值 → 有时"先出手一次"比多一点攻击更值钱；
- ❌ 每局都用同一套思路 → 每局角色池都会重新抽，且**双方不会拿到同一名角色**。

## 五、常见问题

| 问题 | 答案 |
| --- | --- |
| 对手中途跑了怎么办？ | 房间会立刻关闭并给出提示，重新创建房间即可 |
| 刷新页面了 | 当前版本会视为掉线（房间关闭）；重新进大厅开一局即可 |
| 为什么我的对手看不到我的角色池？ | 角色池是本局私有的，只有提交后双方的阵容才会同时公开 |
| 刷新页面会掉线吗？ | 不会。90 秒内会自动回到原房间和原来的座位，已提交的方案也保留 |
| 同一台电脑能开两个标签页对战吗？ | 可以，两个标签页各自独立，互不干扰 |
| 打完想看细节 | 战报页可以暂停/加速/跳到结果；备战页右上角还能回看**上一局战报** |
| 怎么知道自己最近打得怎么样 | 大厅底部会显示最近 5 场战绩（保存在你自己的浏览器里） |
