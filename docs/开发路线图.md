# 开发路线图

原则：**先把一条完整链路做扎实，再往上叠内容。**
每个版本都必须满足「main 分支可运行 + 测试全绿 + 文档同步更新」，并打一个可回退的 tag。

## 已经做完的版本

### v0.1.0 地基

三层架构（core / web / frontend）、12 角色 9 标签、战斗引擎与事件化战报、房间状态机、
命令行与对拍工具，以及规则 / 架构 / 协议 / 部署 / 版本管理文档。

### v0.3.0 内容扩展到旧项目规模

- 角色池扩到 **20 名**（对齐旧项目 v1.2 的定稿数值）；
- 新增 **吸血 / 反弹 / 斩杀** 三个标签，引擎新增「受击后」结算阶段；
- 测试扩到 57 项。

### v0.4.0 / v0.4.1 平衡与抽池

- `tools/balance.py` 对拍工具（角色抽到率 / 出战率 / 出战胜率 / 标签胜率 / 先手优势）；
- 抽池机制改为「20 张共用抽 12 张 + 462 种切分择优」：双方不重复、两边强度接近；
- 一轮平衡把 **20 名角色全部收敛到 45%~55%**（8000 场对拍），并用测试守住角色差异性；
- 浏览器实测修掉两个真实问题：回放吃掉备战时间、再来一局进不了新对局。

### v0.4.2 打磨版

- 面向玩家：邀请链接、最近战绩、上一局战报回看、倒计时变红提醒、回车提交；
- 鲁棒性：消息大小上限、连接限流、兜底异常、安全响应头、断线自动重连；
- 清理：移除旧手写碎片（出处写进 [项目历史](项目历史.md)），补 [玩家指南](玩家指南.md)。

### v0.5.1 匹配与房间机制

- **随机匹配**：FIFO 队列、可取消、按模式隔离；
- **断线重连**：座位 token + 90 秒宽限，刷新页面自动回到原座位并恢复已提交方案；
- 掉线不再立刻毁房；会话存 sessionStorage（多标签页互不干扰）。

### v0.6.0 / v0.6.1 三种模式与模式隔离

- **模式配置化**：`ModeConfig` 描述池子大小、出战人数、增益次数、随机标签与互斥规则；
- **混沌模式**：角色与标签脱钩，每人 4 个随机标签、单角色最多 2 个；
- **大战场模式**：9 选 5、6 次增益；
- **模式隔离专项**：房间模式以创建者为准、匹配按模式排队、大厅偏好与房间模式分离（均含回归测试）。

## 下一步方向（按建议优先级）

### 0. 卡牌模式（v0.8.0，交互大版本第二步）

目标：把「点按钮」升级成「摆卡牌」，默认卡牌模式，可切回按钮模式。

- [ ] **状态与视图分离**：把备战逻辑抽成动作层（上阵 / 换位 / 加增益 / 减增益 / 撤销），
      卡牌视图与按钮视图只是同一份状态的两种皮肤，切视图不丢方案；
- [ ] **上阵用拖放**：手牌区拖到出击位；拖动已上阵的卡调整顺序；拖回手牌区即下阵；
      移动端用 pointer events 自绘拖拽（长按 150ms 启动），点选落位始终保留为等价路径；
- [ ] **增益筹码可视化**：筹码可拖到卡上，也可点筹码再点卡；卡上直接显示 `+攻 / +血` 标记；
- [ ] **低多边形棋子美术**：每个角色一个 SVG 棋子（手绘多边形，剪影可辨），
      风格参考国际象棋：不追求写实，靠"手里的道具"区分——剑 / 盾 / 弓 / 杖 / 药瓶 / 巨炮 / 骷髅 / 荆棘等；
      颜色按星域区分（怒火橙红、重装钢蓝、迅流青、蚀骨黄绿、幽暗紫、重生青白、守护金、毁灭暗红、平衡灰蓝）；
- [ ] 标签图标：12 个标签各一个几何徽记，叠在棋子右下角；
- [ ] **UI 偏好**：`nc_ui = cards | buttons`，默认卡牌，随时切换，保存在本地；
- [ ] 交互回归脚本：两种视图 × 三种模式（3 位 / 5 位）的完整备战流程自动跑一遍。

### 1. 观战模式（v0.9.0）

旁观者只收战报、不参与提交；天然要复用这次的模式隔离（观战者必须与房间模式对齐）。

- [ ] 房间支持观众连接（人数上限，例如 4 人）；
- [ ] 观众视角：双方阵容 + 战报 + 比分，**提交前不显示任何私有信息**（角色池不算）；
- [ ] 前端「观战」入口：房间号 + 观战按钮；观众离开不影响对局；
- [ ] 测试：观众不能提交方案、离开不会关房、模式一致。

### 2. 匹配体验细化（v0.7.x）

- [ ] 排队时显示已等待时长与同模式在线人数；
- [ ] 匹配成功的明显提示（音效或动画）；
- [ ] 公开房间列表（可选择加入正在等人的房间）；
- [ ] 连胜/连败之类的轻量记录（暂不做段位，避免过早引入匹配分层）。

### 3. 复盘与可观测（承接被顺延的体验项）

- [ ] 对局复盘导出（文本 / JSON，含随机种子，便于复现）；
- [ ] 平衡数据面板：按模式统计角色胜率 / 出场率 / 先手胜率；
- [ ] 前端错误提示带 request id，方便对照服务端日志。

### 4. 移动端打磨

- [ ] 小屏下角色卡与出击位的进一步简化（点选自动落位、长按看说明）；
- [ ] 5v5 战场在手机上的布局验证。

### 5. 大战场单独平衡

- [ ] 给对拍工具加 `--mode`，跑一轮大战场专属对拍（团队型标签在 5v5 里权重很可能偏高）；
- [ ] 视结果单独调整该模式数值（模式配置已支持差异化，不必动全局常量）。

### 6. v1.0 正式版要件

- [ ] 账号与战绩（可选轻量登录）；
- [ ] 房间状态外置（Redis），支持多实例水平扩容；
- [ ] 监控、告警、备份与容量估算；
- [ ] 完整运维手册与回滚演练。

| 问题 | 当前状态 | 需要决定什么 |
