# 历史归档

这里保存项目最早期的形态，仅作设计参考，**不参与构建、测试与静态检查**。

## 目录

| 目录 | 时间 | 内容 |
| --- | --- | --- |
| `NCinit/` | 2026-02 | 手写规则碎片：12 角色 / 9 标签的初版实现、对战循环、以及当时对「后端化」的思考笔记 |
| `Code/CL1/` | 2026-02 | 更早的第一版碎片：6 名角色的极简实现与前端联机的初步尝试 |

## 为什么保留

- 这些碎片是玩法的**原始出处**，`docs/规则设定.md` 里的很多裁定都能在这里找到影子；
- 它们记录了当时的思考（哪些地方要拆成「传入参数 → 返回结果」、哪些交互属于玩家、哪些属于战场）；
- 保留它们，是为了以后回看设计演变时不用去翻旧仓库。

## 注意

- 代码风格与当前项目完全不同（全局变量、交互式 `input()`、没有测试），**不要复用**；
- 真正被放弃的实现保存在本仓库 `legacy/novaclash2` 分支（旧的 NovaClash2 服务端与前端），
  需要对照时用 `git show legacy/novaclash2:server/game/engine.py` 之类的方式查看；
- 当前项目的一切规则以 [docs/规则设定.md](../docs/规则设定.md) 为准。
