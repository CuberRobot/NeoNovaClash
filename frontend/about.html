Project

两个人，各自六张牌，三局两胜
——赢在部署，不赢在手速

NeoNovaClash（星陨竞技场）是一个浏览器里就能玩的 1v1 策略对战：每局你只做三件事——选出 3 名星灵、分配 4 次增益、定下攻击策略。 提交之后战斗由服务端一次性演算，再用动画逐条放给你看。你决定不了每一次挥砍，但你能决定整场对局的形状。

  • 6 → 8整场固定池 + 每局补 1 张
  • 3 局三局两胜，同一份池子
  • 20名角色 / 12 种标签
  • 3标准 / 混沌 / 大战场

核心乐趣：猜对手会怎么用他那 6 张牌

大部分自动战斗游戏每局重新发牌，猜对了也没有第二局。这里不一样—— 整场三局共用同一份角色池，双方不重名，打完一局还能各补一张（第二局 7 选 3、第三局 8 选 3）。

第一局是侦察

对手先上谁、把谁放第 1 位（先手方在第 1 位先出手）、增益给了谁——全是线索。

第二、三局是反制

池子只增不减，你可以换阵容、换策略，专打他上一局暴露出来的软肋。

先手值就是筹码

出战角色先手值总和较低的一方先手。想抢先后手，就得接受更难抢的阵容强度。

出手顺序是位次优先、同位次先手方先动：先手方是 A 时是 A1→B1→A2→B2→A3→B3；先手方是 B 时整体镜像。

一局是怎么打完的

  1. 两人进入同一个房间（房间号 / 邀请链接 / 随机匹配），系统抽一份 12 张的卡池，对半切成两个 6 张池，双方不重名。
  2. 备战：拖牌上阵、排好出击顺序、把 4 次增益（攻击 +2 / 生命 +4）分配给出击位、选一个攻击策略。
  3. 双方提交（或 90 秒超时由系统随机提交）后自动演算，战斗逐条演出。
  4. 先赢 2 局者拿下整场；双方可一键「再来一局」重开一场（重新抽池）。

看演算不吃准备时间：上一局回放播完（或点「跳到结果」）之后，下一局的倒计时才真正开始。

做得比较用心的几处

拖牌上阵

默认卡牌模式：手牌拖到出击位、拖动换位、拖回手牌即下阵；不习惯拖放可一键切回按钮模式，两种视图共用同一份方案。

战斗有演出

两军左右对峙，冲刺、弹道、伤害飘字、滞后血条、阵亡碎裂、复活与震屏，配 CC0 开源音效；可暂停、加速、跳关键节点、重播任意一局。

随时能回来

90 秒断线重连：刷新页面自动回到原来的座位，已提交的方案还在；对局结束后重连也会停在胜负结算页。

技术实现

刻意选了"能长期维护"的组合：服务端 FastAPI + WebSocket，前端零构建的原生 JS， 规则层不依赖任何 Web 框架，因此可以用命令行、机器人或测试直接跑完整场对局。

分层 core 纯游戏逻辑（角色池 / 方案校验 / 战斗引擎 / 房间状态机）→ web HTTP 与 WebSocket 传输 → frontend 原生 HTML/CSS/JS
可复现 每场战斗都有随机种子，相同输入必然得到同一份战报，便于复盘与平衡分析
平衡工具 tools/balance.py 支持单局与整场对拍（--matches）， 输出角色胜率、先手优势、补卡前后的对照
质量门禁 109 项测试 + ruff 全绿；每个里程碑一个 tag，随时可回退
部署 systemd + Cloudflare Tunnel（源站不暴露端口），一键更新脚本 deploy/update.sh

最近做了什么

v0.10.0 · 补卡

整场固定池 + 每局补 1 张（7 选 3 → 8 选 3），并补上整场平衡对拍：座位 49.6/50.4，逐局先手 54.3%。

v0.12.0 · 练习模式

一个人也能直接开一局：电脑对手走完全相同的规则，界面明确标注是电脑；另外备战页现在会显示对手是谁。

v0.9.0 · 规则修正

角色池整场固定、回放不再吃备战时间（倒计时等双方看完回放）、备限 60→90 秒、赛后重连仍停在结算页。

v0.8.0 · 交互大版本

卡牌模式上线（拖放上阵）、战斗改成舞台式逐条演出、接入 CC0 音效、前端拆成五个零构建模块。

更早

三种玩法模式、平衡对拍、匹配与房间机制、断线重连、低多边形棋子与标签徽记素材。
