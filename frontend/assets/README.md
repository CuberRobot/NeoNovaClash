# 美术素材（低多边形棋子）

这里存放游戏用的 SVG 素材。**全部由脚本生成**，不是手工逐个画的文件，
所以风格统一、改参数即可整套重出。

## 目录

| 路径 | 内容 |
| --- | --- |
| `pieces/piece-01.svg` … `piece-20.svg` | 20 名角色的棋子（编号与 `backend/core/characters.py` 的角色 id 一一对应） |
| `tags/tag-<key>.svg` | 12 个标签徽记（文件名与标签 key 一致，如 `tag-berserk.svg`） |
| `preview.html` | 素材预览页（**只是审阅工具，游戏里不引用**）：<http://127.0.0.1:8000/static/assets/preview.html> |

## 重新生成

```bash
./venv/bin/python -m tools.art.generate_assets
```

生成脚本在 [tools/art/generate_assets.py](../../tools/art/generate_assets.py)，
可以直接改：调色板、体型（`BUILDS`）、道具形状、以及每个角色的道具与细节（`pieces()`）。

## 设计约定

**构图语法**（保证 20 个棋子摆在一起像一套）：

```
底座 → 腿 → 躯干（暗面 + 亮面 + 左侧高光棱）→ 肩甲 → 头 + 面甲 → 手臂 → 手心连接点 → 道具 → 细节
```

**靠手里的东西辨人**（国际象棋式思路）：剑 / 塔盾 / 长弓 / 法杖 / 提灯 / 双斧 / 巨刃 / 药瓶 /
多管炮 / 晶核 / 短刃 / 荆棘环 …… 远看剪影不同，近看才有细节。

**靠主色区分星域**（`PALETTES`）：

| 星域 | 主色 | 角色 |
| --- | --- | --- |
| 平衡星域 | 灰蓝 | 均衡战士 A~E |
| 碎晶星域 | 橙 | 自爆步兵 |
| 幽暗星域 | 紫 | 诅咒巫师、噬魂者 |
| 重生星域 | 青白 | 死灵法师 |
| 重装星域 | 钢蓝 | 铁甲卫士、晶壁守卫 |
| 守护星域 | 金 | 护盾部署者、荆棘守卫 |
| 迅流星域 | 青 | 风行射手、暗影猎手 |
| 怒火星域 | 橙红 | 狂战士、血怒斗士 |
| 蚀骨星域 | 黄绿 | 毒药投手 |
| 毁灭星域 | 暗红 | 重炮统领、处决者 |

## 使用约定（给前端）

- 棋子 `viewBox` 固定 `0 0 64 64`，徽记固定 `0 0 24 24`，任何尺寸都能直接用；
- 建议尺寸：手牌 48~56px、出击位 64px、拖拽跟随 88~96px、战绩列表 28px；
- 标签徽记叠在棋子右上角（18~22px）；
- 需要"标签被剥夺 / 已阵亡"的效果时，用 CSS 滤镜即可，不需要第二套素材：
  `filter: grayscale(1) brightness(0.7)`；
- 选中态用外框 + 微光，不要改素材本身的颜色。

## 待打磨（可继续迭代）

- 均衡战士 A~E 目前只有道具与体型不同，可再给个体差异（例如披风角、肩甲形状）；
- 晶壁守卫的三层晶壁可以再立体一点（错位 + 高光）；
- 32px 小尺寸下，双斧与荆棘环的细节会糊，将来可以按尺寸切换简化版；
- 群伤 / 反弹两个徽记的区分度还可以再拉开。
